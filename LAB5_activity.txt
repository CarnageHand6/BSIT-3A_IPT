Array in PERL

Learning Objectives
After completing this laboratory activity, students will be able to:

1. Demonstrate the use of Perl arrays and the index() function.
2. Apply conditional statements to validate user input.
3. Implement loops to allow repeated user choices.
4. Identify the index position of elements in an array.
5. Develop simple interactive Perl programs simulating real-life scenarios.
6. Handle error handling by displaying Invalid Input.

Procedures

1. Create a Perl program named: LASTNAME_FruitsStore.pl
The program must:

1. Display the heading "LASTNAME Fruits Store" centered.
2. Show a list of available fruits.
3. Ask the user if they want to add a fruit.
   o If YES:
     - Input fruit name.
     - If fruit already exists, display:
       "Fruit already exists at index [n] in the list."
     - If not, add fruit to the list and display the updated list.
     - Ask if the user wants to add again.
   o If NO:
     - Display the list of fruits.
